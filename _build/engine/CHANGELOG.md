# PZ 引擎版本紀錄

新的放最上面。版本規則見 `HANDBOOK.md` 第 16 節：修訂版（1.0.x）只修 bug，寫 `"engine": "1.0"` 的遊戲重新組建時自動用到；次版本（1.x.0）加功能，遊戲要自己改 `pz.json` 才會用；已發布的 `releases/` 檔案永遠不改。

## 1.1.0（2026-11-14）

精緻化四大塊：畫面光影、角色動畫、世界與地圖、介面與聲音。寫 `"engine": "1.0"` 的遊戲不受影響；要用新功能把 `pz.json` 改成 `"engine": "1.1"`。

精緻化第一塊：畫面光影。

- 光影 `PZ.light`：環境光＋點光、手電筒（錐形）、閃爍、跟隨物件、光源光點；牆／柱子／箱子／用圖形狀擋光，距離場（JFA）算柔和陰影與半影；牆上的火把放在牆裡也照得出去；牆面朝燈那側有亮邊；環境光區塊（屋內暗、院子亮、側視遊戲的天空）；打雷閃光；`PZ.light.at()` 亮度查詢、`PZ.light.blocked()` 視線檢查；畫質自動降解析度與步數；Canvas2D 後備有光沒有陰影。
- `g.lighting()`（沒呼叫時 `g.hud()` 自動套）、`g.castShadow()` 角色投影（自動朝離燈方向、側視 `flat`）、`g.beam()` 光束（新的繪圖模式：梯形也不會折一下）。
- 天氣 `PZ.weather`：雨（濺起水花）、毛毛雨、雷雨（分岔閃電、照亮、延遲雷聲）、雪（近的有景深光暈）、暴風雪、濃霧／薄霧（會被燈照亮、燈在霧裡有光暈）；風、淡入淡出、鏡頭視差、燈下閃亮；跟著畫質調數量；換場景自動清。
- 水面與熱浪：`g.water()` 側視倒影（波紋、水面亮線、倒影隨深度淡掉）、俯視水窪（波光、水下扭曲、橢圓柔邊）；`g.haze()` 熱浪扭曲。
- 電影感：`PZ.post.grade()` 16³ 調色表、14 種預設（電影、冷、暖、黑白、舊照片、恐怖、夢境、夜晚、夕陽、霓虹、毒氣、鮮豔、漂白、復古）＋自訂（曝光、色溫、對比 S 曲線、暗部／中間調／亮部、飽和、自然飽和、分離色調、霧面、單色），換調色自動淡入淡出；`PZ.fx.letterbox()` 電影黑邊。
- 除錯面板顯示燈數與天氣。
- 樣品館新增「光影」「天氣與水面」兩間。

精緻化第二塊：角色動畫。

- `PZ.juice` 程序動畫：一張圖的角色會呼吸、走路起伏搖擺、前傾、紙片轉身、起跳拉長、落地壓扁、受擊抖動閃白（彈簧、自己的時間軸，不受場景補間清除影響）。
- `PZ.chain` 鏈子（verlet、固定小步長、釘住點在小步之間平順移動）：披風、圍巾、尾巴、頭髮、羽飾、繩子；彎曲剛性、根部方向、地面、外力、跟著天氣的風；`g.chain()` 畫成帶子。
- `PZ.animator` 逐格動畫狀態機：自動找 `name:0…`、循環／播完接下一個、某一格發事件、播放進度。
- `PZ.rig.humanoid` 骨架角色：只給部位圖就有站立呼吸、走路（不滑步）、跑步（騰空、後腳踢）、空中（上升／下墜不同姿勢）、落地壓扁、蹲、受傷、倒下（彈一下）、爬起來；七種招式（揮砍、橫掃、突刺、上挑、重擊、出拳、施法）可連段、出招判定事件、自訂招式關鍵格（含手腕）；腳用兩段 IK 踩地形、腳底貼坡度；轉身壓扁翻面；披風／羽飾／頭髮／圍巾自動跟著身體飄（不穿地）；刀光自動畫；`g.rigShadow()` 貼地影子；`joint()`、`tip()` 拿手和武器尖端位置；除錯骨架線。
- `g.swoosh()` 刀光：兩條邊之間的弧形殘影（Catmull-Rom 細分，掉幀也圓滑）。
- `PZ.art.make` 新選項：`outline` 外框（圖自動放大、anchor 不跑位）、`rim` 朝光亮邊、`shade` 下半部陰影。
- 自我檢查 125 項（Chromium、WebKit 都過）。
- 樣品館新增「角色動畫」：黃昏訓練場的騎士（三連段、重擊、施法、受傷、倒下）、腳踩起伏的草地、跟在後面甩尾巴的小狐狸、會呼吸跳躍的史萊姆與木樁（可以關掉程序動畫對照）。

精緻化第三塊：世界與地圖。

- `PZ.tilemap` 格子地圖：多層、文字畫地圖、方塊撞牆滑動（自動分段不穿牆、單向平台）、射線（DDA）、視線、視野（遞迴陰影投射）、最近的空地、自動接邊遮罩（4／8 方向）、合併大方塊、一行讓牆擋光（2.5D 牆可往上抬）、`behindWall()`（2.5D 被牆擋住的點）；`map.draw()` 只畫看得到的格子，角色依腳底跟牆一列一列交錯（同列先牆後人：站在牆邊不會被切掉）。
- 尋路：`PZ.path.find`（A*、二元堆積、八方向不切牆角）、`PZ.path.smooth`（拉直）、`PZ.path.flow` 流場（一次 Dijkstra 給所有怪方向，目標換格子才重算，方向雙線性內插）。
- 程序生成 `PZ.gen`：地牢（房間＋最小生成樹走廊＋環路）、洞窟（細胞自動機＋只留最大連通區）、島嶼高度圖、雜訊、均勻散布（Poisson disc）、離牆距離、連通區；`PZ.iso` 斜 45° 換算。
- 地圖畫法 `PZ.tiles`：2.5D 地牢、圓滑洞窟（兩段懸崖面、岩頂材質、亮邊、螢光菇）、島嶼（會進退的浪花、浪頭、沙灘、草地、岩石等高線）；`PZ.tiles.contour` 等高線快取（算一次、按列畫）、`PZ.tiles.marching` 即時版（可切列、可貼材質、朝南亮邊）、`PZ.tiles.soften`。
- 材質：`PZ.art.pattern()` 會一直重複的材質（GPU 重複取樣）＋`g.polyTex()` 任意形狀貼材質（材質座標自動縮小，手機半精度不糊；Canvas2D 畫平均色）；`PZ.art.make(…, { wrap: true })` 鋪滿的地板接縫不再有細線。
- 自我檢查 136 項。
- 樣品館新增「世界與地圖」：一鍵生成地牢、洞窟、島嶼；上百隻空殼／史萊姆用流場繞牆追人；點地圖自動找路（路線光點）；戰爭迷霧、小地圖、火把與水晶的光影；可以打開流場箭頭看怪物怎麼找路。

精緻化第四塊：介面與聲音。

- HUD 元件：`PZ.meter` 血條（受傷殘影停一下再退、補血預覽、閃白抖動、低血量閃爍、刻度、三種形狀）、`PZ.count` 會滾的數字（千分位、每跳一下 tick、變大一下）、`g.cooldown` 技能冷卻（扇形掃開＋外圈亮邊＋好了閃一下）、`g.arc` 圓弧、`g.pie` 扇形、`g.rrect` 圓角框（可加框線）、`g.quad` 任意四邊形漸層、`g.strokePoly`、`g.meter`、`g.count`。
- 介面（DOM）：`PZ.ui.tip` 提示框（滑鼠、手指按住、手把焦點都會出現，自動擺位）、`PZ.ui.holo` 閃卡（傾斜、亮面、彩虹箔）、`PZ.ui.slots` 格子背包（稀有度光暈、傳說繞光、數量、新東西小點、提示框）、`PZ.ui.title` 標題畫面（字一個個浮上來、掃光、選單）。
- 轉場新增五種：菱形、百葉窗、快門、推門、方塊。
- 環境音 `PZ.amb`：雨、雷雨、風、森林、夜晚、洞窟、海邊、城市、營火、船艙、溪流，全部即時合成（循環雜訊底＋陣風／浪湧／濾波掃動＋隨機事件：鳥、蟲、水滴、木柴爆裂、喇叭、船板），可以同時混好幾種；`follow(true)` 跟著天氣自動換。聲部滿的時候先讓環境音讓位。
- 配樂：新樂器 epiano、piano、guitar、kalimba、brass、supersaw；聲部效果 `delay`（跟拍子對齊的回音）、`lp`（給兩個值時隨緊張度打開）、`pump`（跟著大鼓一縮一放）；`play(…, { sync: 'bar' | 'half' | 'beat' })` 對拍子換歌、`stinger` 也能對拍；`muffle()` 配樂悶住；`phase()` 拍子進度。
- 新音效 17 個：六種地面的腳步、介面第二組（select、back、toggleOn／Off、slider、unlock、purchase、equip、page、rare、combo）。
- 自我檢查 154 項。
- 樣品館新增「介面與聲音」：海邊懸崖上的營火之夜——頭像、經驗值環、血條、魔力條、分數、連擊、四個技能（點技能或點稻草人）；抽卡（閃卡）、背包、標題畫面、轉場輪播；十一種音景可以同時開；探索／戰鬥／頭目三首配樂對拍子切換、打得越兇濾波越開，還能「悶住」。

## 1.0.2（2026-11-14）

- 省記憶體（iPhone 閃退的頭號原因）：第一張圖集先開 1024×1024（小遊戲省 12 MB），放不下再開 2048；背景合成音效的執行緒算完就收掉，之後有新音效要算再開。WebKit 量測《最後一單》遊戲中最高 588 MB（1.0.1 是 622 MB；舊版純 Canvas2D 是 526 MB）。

## 1.0.1（2026-11-14）

- `PZ.fx.hurt` 的紅暗角改短、改淡（被一群怪連續咬時畫面不會一直是紅的）；可以 `{ vignette: false }` 不要暗角（遊戲自己有受傷紅邊時）。

## 1.0.0（2026-11-14）

第一個正式版。

- 繪圖：WebGL2 批次繪圖（七種模式：貼圖、純色、圓、環、柔光、線、剪影），每批最多 8192 個方塊、8 張貼圖；WebGL 遺失時恢復（圖集用畫圖函式重畫），救不回來換 Canvas2D。
- 後製：雙 Kawase 泛光（以人眼亮度判斷：鮮豔的美術不會整片發光，疊加發光才會）、最多 4 道衝擊波扭曲、色差、暗角（可變色）、顆粒、掃描線、老電視彎曲、調色、全畫面閃光。
- 圖集：天際線打包（2048 頁）、程式畫圖 `PZ.art.make`、動畫格、外部圖片、畫布貼圖、即時貼圖 `PZ.art.live`（舊遊戲搬家用）。
- 中文字型圖集與斷行（標點不放行首、英文單字不拆）；Canvas2D 模式用原生文字。
- 時間：可變／固定步長、打擊停頓、慢動作、帶原因的暫停、計時器、自訂系統；自動畫質（記住這台裝置降過的階）。
- 輸入：動作對應（鍵盤、滑鼠、手把、觸控）、浮動／固定搖桿（場景裡建的離開場景自動拿掉；從鍵盤換回手指的第一下就抓到搖桿）、觸控按鈕、手勢、手把震動、手機觸覺（iPhone 用系統開關觸感）。
- 相機：trauma 震動、後座力、推近、跟隨、取景、邊界、戰略鏡頭操作、外部鏡頭模式（舊遊戲搬家用）。
- 補間、彈簧（場景結束自動清）、18 種粒子、`PZ.fx` 打擊感套餐。
- 聲音：同步解鎖、iPhone 靜音鍵修正、四條匯流排、限幅器、殘響、47 個合成音效（背景執行緒算）、文字寫譜配樂（緊張度分層、短樂句、音檔）。
- 存檔：自動存＋備份＋migrate＋存檔碼＋多欄；Claude 版雲端存檔；設定沿用到別款（可 `{ local: true }` 只改這款）。
- 介面：對話框、選擇、提示、大標題、載入畫面、標準設定頁（可加自訂列）、暫停選單、劇情對話（自動、快轉、紀錄）、手把／鍵盤焦點導覽、五套主題。
- 除錯：錯誤面板（複製錯誤給 Claude）、效能面板、`window.__pz` 測試掛鉤。
- 《PZ 遊戲收藏》：PZ 圓鈕選單打開時引擎暫停、發 `hub` 事件。
- 工具：`pzbuild.py`（Claude 版＋網頁版、字型子集、圖示）、`test_engine.py`（單元 15、自我檢查、點擊觸控、雲端存檔情境 27、範例 4、效能）、`webkit_check.py`（Safari 引擎）。
