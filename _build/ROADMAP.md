- 2026-11-10：修**每次打開都先閃一下空白畫面**（PZ 錄影回報：滑掉重開也一樣）。原因：收藏庫先把頂列和分頁列畫出來，再去網路拿 `catalog.json`，拿到了才放開機畫面，中間約 0.3～0.6 秒露出半成品的大廳。改成 `index.html` 一開始就有啟動底圖 `#prelude`（開機畫面的暗底，樣式寫在 `index.html` 裡），開機畫面直接從它接手；不放開機畫面時等首頁畫好才淡出；網路很慢時中間有一條細光在呼吸。順手修 2.0 的一個漏洞：開機畫面改成要按 PRESS START 以後，打開時排好的「新遊戲入庫」、更新公告、獎盃橫幅會在開機畫面底下跳完、看不到，現在等按下去才出來；提示泡泡碰上獎盃橫幅時排在橫幅下面，不再疊在一起。`smoke.py` 加啟動檢查（目錄故意晚到時畫面上只能是底圖；停在 PRESS START 時不能先跳提示；舊版這兩項都會被抓出來），WebKit 錄影確認第一格就是底圖。
