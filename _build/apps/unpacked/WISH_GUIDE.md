# 解包 UNPACKED — 願望單解包指南

每天的排程（Claude 排程任務「解包：願望單解包」，台灣時間 16:37）照這份做：**痞子葳加進 Steam 願望單的遊戲，每一款都寫一篇深度解包，附「買不買」判定和目標價。**
寫法跟每日專題一樣深（照 `WRITER_GUIDE.md`），差別是：題目從他的願望單來、`kind` 是 `wish`，而且一定要有 `buy`。App 的「獵價」會把判定和目標價貼在每一款上，價格跌到目標價就跳「到價」警報、隔天早上推播提醒。
所有內容一律**繁體中文、台灣用語**；稱呼他「痞子葳」。

---

## 0. 準備

1. 用 add_repo 加 `PZWei0105/PZ-Games`（要 push 權限），clone 到 `/home/claude/pz-games`，再用 register_repo_root 登記。
2. 讀 `apps/unpacked/data/` 的 `wish.json`（`state` 不是 `ok` 就直接結束、不推播）、`index.json`、`picks.json`、`wish-skip.json`（沒有這個檔就當作空的），和 `WRITER_GUIDE.md` 全文。

## 1. 今天寫哪幾款（跟 App 顯示的「解包排隊」一樣）

- 排隊名單：`wish.json` 的 `items` 裡，不是 `adult`、`appid` 不在任何一篇專題（`index.json` 的 `steam`）和推坑（`picks.json` 的 `steam`）、也不在 `wish-skip.json` 的遊戲，照 `added`（加入願望單的日期）**由新到舊**排。
- 每次寫排在最前面的 **2 款**（App 上顯示「每天寫 2 款」）。素材真的不夠就只寫 1 款。
- **排隊名單是空的：什麼都不做、不 commit、不推播，直接結束**（這是正常狀況）。
- 不寫解包的放進 `wish-skip.json`（格式 `{"appid": "理由"}`），這些不算在 2 款裡、也會從排隊名單拿掉：
  - 不是遊戲本體的：DLC、原聲帶、美術集、軟體、試玩版（`name` 或商店頁看得出來）。
  - 以性內容為主打的成人向遊戲（理由寫「成人向」）。
- 已經寫過專題或推坑的不用再寫（App 會直接用那篇）。

## 2. 研究與寫稿

照 `WRITER_GUIDE.md` 第 2～5 節：每款至少 8 個來源、資訊卡、課金雷達、中文與台灣、你的 SCAR 18、預告、玩法、第一個小時、跟誰像、劇情、幕後、時間軸、風向、討論、粉專稿全部寫滿，不能比範例專題薄。差別：

| 欄位 | 要求 |
|---|---|
| `kind` | `wish`，`kind_label` 是「願望單解包」 |
| `date`、`rank` | 今天；`rank` 從 20 開始編（排在每日專題後面） |
| `game.steam` | 一定要填（就是願望單上的 appid） |
| `verdict` | 照常寫推薦／觀望／不推薦（這是「好不好玩」） |
| `buy` | **一定要有**（這是「現在該不該花錢」），見第 3 節 |

已經上市很久的遊戲也照寫：重點放在「現在玩還值不值得」（更新、DLC、玩家現況、伺服器）。還沒上市的照即將推出的專題寫法。

## 3. 買不買（`buy`）

```json
"buy": {"call": "等特價", "target": 30000, "why": "……", "watch": "……"}
```

- `call` 只能是：**現在買**（現價就值得）、**等特價**、**等史低**、**等上市後評價**（還沒上市或剛上市評價未定）、**先觀望**（遊戲本身有疑慮）、**別買**。
- `target`：目標價，單位「分」（NT$300 寫 `30000`）。`等特價`、`等史低` 一定要填；`現在買` 可以填現價；`別買`、還沒有價格的填 `null`。
- 目標價要有根據：查這款過去在 Steam 台灣區的特價紀錄（例：SteamDB 的價格歷史、Steam 季節特賣的折扣），寫在 `why` 裡並把來源放進 `sources`。查不到過去紀錄就用同類型、同發行商常見的折扣幅度估，`why` 裡講清楚是估的。
- `why` 40～260 字：為什麼這樣判、目標價怎麼來的，扣回痞子葳的口味和時間（推坑指南第 1 節）。
- `watch`（選填）：什麼情況會改判（例：上市後評價、大型更新、出完整版）。

## 4. 獨立查核、上架

- 用 Agent 工具開一個沒看過寫作過程的子代理獨立查核（同 `WRITER_GUIDE.md` 第 5 節，**目標價的根據也要查**），照它的回報修正。
- `python3 _build/apps/unpacked/tools/publish.py`（BAD 一定要修到 0）
- `git add apps/unpacked/data/features apps/unpacked/data/index.json apps/unpacked/data/track.json apps/unpacked/data/wish-skip.json`
- commit「解包：MM/DD 願望單解包（遊戲 A、遊戲 B）」，結尾附上當次規定的署名行；`git pull --rebase origin main` 後推上 main（失敗重試最多 3 次）。

## 5. 回報

用 PushNotification 推播給痞子葳（一行、200 字以內、繁體中文）：開頭「願望單解包：A、B」，各用很短的話說判定和目標價（例：「A 等特價，目標 NT$300」「B 現在就值得買」）；排隊還有幾款一句帶過。不寫技術細節。
