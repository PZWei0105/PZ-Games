原則照痞子葳的要求：品質優先、去蕪存菁，不為了湊數加功能。

## 待辦（等痞子葳決定或提供）

  不要從舊對話逐字重抄：2026-11-11 試過，被安全機制擋下。已經抄出來、還沒上架的幾章（5、6、7、8、10、12、13）當時放在工作區，沒有進 repo；拿到原檔後以原檔為準。
- 其他小說（《靜默帶》《嘴上不說》《異史未完》《祖龍》《一路好走》《帝殤》《魏賊》）都還沒上架，同樣等原檔。上架前先問哪幾部要放。
- **說書的聲音還沒定**：痞子葳要台灣口音、像 YT 說書頻道的男聲。候選：
  1. 筆電用 Edge 開 App，裝置語音選 YunJhe（台灣腔男聲）先聽聽看是不是要的聲音；
  2. 是的話，用微軟官方 Azure 語音服務錄音軌（每月 50 萬字免費額度，要他開帳號給金鑰；雲端沙盒連不到 Azure，要在他的筆電或 GitHub Actions 跑），`narrate.py` 加一個引擎；
  3. 或在他的 RTX 5090 筆電跑聯發科 BreezyVoice（台灣口音開源模型，5 秒樣本，可以用他自己的聲音）。
  定案後才整本錄；現在書架上的音軌只是示範。
- 小說全文目前是「打包但沒加密」。他如果要真正上鎖：章節用公鑰加密、私鑰用通關密語保護，每台裝置輸入一次。

## 可以做、還沒做（要真的加分才做）

- 簡體書一鍵轉繁體（匯入的 TXT／EPUB 很多是簡體）。
- 直排（由右到左）排版。
- 音軌離線下載（現在要連網才能播）。
- 劃線與筆記、閱讀統計：討論時他沒有選，不要主動加。
- PDF、MOBI：目前明確不支援（PDF 重新排版品質不好）。

## 已知問題

- 上線前檢查用的是 Chromium，沒有在真的 iPhone 上測過：仿真翻頁的手感、鎖屏播放、加入主畫面後的行為，要等痞子葳回報。
- 音軌放在 Pages 的 repo 裡，一章 6～12 MB；錄到上百章會逼近 1 GB 上限，到時候要搬（另一個 repo 的 Pages，或 Releases）。
- 裝置語音在 iPhone 鎖屏後會停（系統限制），App 會在朗讀時讓螢幕保持開著。
