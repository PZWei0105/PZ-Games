# 補番 BINGE

痞子葳的動畫放映室（2026-11-18 上線）：只有動畫的 YouTube。AI 漫劇、沙雕動畫、動態漫畫，加上官方頻道的日本動畫、國漫、卡通。
網址：https://pzwei0105.github.io/PZ-Games/apps/binge/

起因（痞子葳 2026-11-18）：先問了「紅果短劇」能不能做類似的 App——不是自己生成，而是收**網路上已經有的動畫**，像《觀戰》是遊戲影片 App，這款是動畫影片 App。
他要的是：**AI 動畫（近年超級爆多）獨立一個分頁**、傳統動畫全收；網路上很多不是一集一集的，而是好幾集剪成一支的**長片合輯，一次都幾十個小時起跳**，很方便。
《解包》有塗鴉風、《觀戰》有電競轉播風，這款要有**動畫的風格**，品質照樣拉滿。

## 設計語言：賽璐璐動畫＋新海式的天空

跟《解包》（塗鴉噴漆）、《觀戰》（電競轉播）、《轉機》（夜間機場）、收藏庫（卡匣主機）都不一樣：
- **賽璐璐**：粗墨線（`--ink`）、硬陰影（每一類一個顏色：AI 紫、沙雕橘、動態漫畫藍、日本動畫粉、國漫紅、卡通黃）、網點、集中線。卡片是一張張「紙面字卡」（縮圖＋米色字卡），區塊標題是描邊大字＋斜色帶＋英文副標，說明是漫畫的旁白框。
- **天空跟著時間變**（`sky-dawn/day/dusk/night`，設定可固定）：平塗的雲往右飄、白天飄花瓣、深夜換成螢火蟲；最下面是屋頂、電線桿、電線的街景剪影，黃昏和深夜窗戶會亮燈。黃昏、深夜整個介面換成深色字卡。
- **每天第一次打開是一段 OP**（設定：每天第一次／每次／不要）：集中線背景上「第 N 話」（打開的第幾天）、「補番 BINGE」大字、今天的一句話 →「開播」→ 白閃 → 三格快切（今天的精選）→ 墨水圈打開進場，然後下面跳出「第 N 話　午後好，痞子葳」的標題卡。
- 換分頁是**墨水圈轉場**（從點的位置收起再打開）。放映機開播前先跳一張**過場卡**（「補番　第 N 集」）、播完是**次回預告**倒數。
- 字型：Dela Gothic One（OFL，`src/fonts/`，只取畫面上用到的字做子集，約 38 KB 內嵌）；其他中文用系統粗體。
- 聲音全部 Web Audio 合成（`sound.js`）：點擊、墨水圈、亮晶晶、扭蛋、蓋章、次回預告、倒數、晚安；背景是 Lo-fi 動畫咖啡廳（Rhodes 和弦、搖擺鼓、每天換旋律的卡林巴琴），白天 82、黃昏 76、深夜 70 BPM，**影片一播就停**。**背景音樂完全不用白噪音**（黑膠底噪、爆擦聲、腳踏鈸、噪音小鼓都拿掉了，小鼓改成音高做的悶響）：疊起來像一直下雨，找動畫時痞子葳嫌吵；他放空時才喜歡白噪音（2026-11-18）。
- 手機記憶體：不用 filter／backdrop-filter／模糊陰影；動畫只動 transform、opacity；粒子畫布用完就拿掉；`[hidden]` 一定要 `display:none !important`；`html, body` 用 `overflow-x: clip`（不然 Ken Burns 放大的圖會把手機版面撐寬，頂列、分頁列跟著跑掉）。

## 資料

### 管線：`.github/workflows/binge-feed.yml`（每 30 分鐘，第 23、53 分）

`tools/pipeline.py`（`ytx.py` 是共用的抓取與標題整理）：
1. **轉發站收件**：App 把追番／取消／稍後再看／封鎖／隱藏作品／長片進度／新增頻道送到 `https://ntfy.sh/pz-binge-7e3572039bf2097cf2bf`（no-cors POST，`{v:1, dev, evs:[…]}`），管線收白名單事件寫進 `apps/binge/data/me.json`（main 分支）。主題在公開程式裡，所以收件一律當不可信資料（格式檢查、截長度）。
2. **頻道名冊**：`apps/binge/data/channels.json`（手寫的精選名單，57 台；`kind` 是 ai／sd／mc／jp／cn／toon，`geo: TW` 是台灣限定頻道）→ `roster.json`（main 分支）。
3. **RSS**：每台最新 15 支（說明欄裡的章節時間碼、播放清單連結也從這裡拿）。
4. **yt-dlp 只抓清單、不下載**（11 分鐘預算、5 條執行緒）：頻道的影片／播放清單／Shorts／直播分頁（20～24 小時一次），播放清單內容（52 小時一次）——片長、觀看數、會員限定、直播狀態都從這裡來。**台灣限定頻道**（木棉花、Ani-One 中文）從美國的 Actions 看不到分頁，改從說明欄找到播放清單再抓（清單抓得到）。
5. **影片頁**：一次最多 60 支補片長、直播中／即將直播、說明欄。
6. **有金鑰（Actions 密碼 `YT_KEY`，跟《觀戰》共用）才做**：台灣限定頻道的播放清單、`videos.list` 補片長與直播狀態。一天上限 4,000 點（免費額度 1 萬）。
7. **整理**（`build_catalog`）：
   - 一律轉台灣繁體（OpenCC s2twp＋t2tw；`臺→台`、`壹→一`）。s2twp 的電腦用語在小說標題常常錯，原文有這些詞就換回來（`_TW_UNDO`：綁定、刷新、對象、循環、激活、支持、發布、類型⋯）。頻道名去掉英文副標（「九界動漫 Nine Anime」→「九界動漫」；黏著的單一英文字是品牌，留著）與「歡迎訂閱」「Get the APP」尾巴（`nice_ch`）。
   - 日文標題（三個以上假名）不收：Ani-One Asia 會上日本 YouTuber 的企劃影片，不是動畫。土耳其文、越南文標題也不收（Regular Show 的清單分頁掛了 Cartoon Network Türkiye 的清單，`_XLATIN`、`_TURK`）。
   - 標題拿掉 hashtag、表情符號、字幕說明、「一口氣看完」「沙雕動畫短片大合集」「加入會員」之類的宣傳字、括號裡的英文翻譯、【玄幻｜修仙｜小說改編】這種題材標籤、被 YouTube 截斷沒收尾的括號（`clean_title`）。
   - 格式：長片合輯（55 分鐘以上，或 35 分鐘以上又寫了合集／集數範圍）、單集、劇場版、Shorts、直播、預告、片段。25 分鐘以下寫著「預告／Trailer」（15 分鐘以下）或「精彩看點／Highlight／高光」的算預告，不放進作品的集數。合輯的集數範圍（1～80 集）、說明欄的章節都留著，放映機用來跳下一集。
   - **作品**：播放清單找各集標題共有的名字（《》裡的最可信，`common_name`；每集都有的分類字「熱血古風漫」輸給只差幾集沒寫的【作品名】；頻道名不算）；找不到時清單名可以當作品名，但「限時免費」「動畫電影」「兒歌」「第二集」「新番」「特別放送」「播放清單」、純題材（「穿越系統」「團寵」）、日文、越南文、土耳其文這種都不算（`_name_ok`）。好幾部湊成的清單（「異世界轉生系列」「新年特別放送」：各集《》名大多不同，`mixed_list`）不是作品。「」『』裡的字只有在標題開頭或緊接集數時才算作品名（句子中間的「刺繡」「小龍蝦」是劇情關鍵字）。同名的合輯（第 1、2 季分開上傳）也會合成一部。作品裡的單集照（季、集數）排好，合輯排在單集後面，單集標題拿掉作品名和重複的集數。
   - 去重：同一部的完整合輯重複上傳只留一支；跨頻道同名、片長差不多的合輯和電影只留觀看最多的。中文頻道裡的外語配音清單不收。
   - **每台有預算**（`BUDGET`：ai 90、sd 90、mc 180、cn 380、jp 620、toon 200，兒童 90；2026-11-20 片庫長到 1.7 MB 時調小）：先挑作品（熱度、新舊、份量）填到八成，再補單支的新片與熱門。作品裡重複上傳的同一集只留一支。片庫大約 10,500 支、590 部作品、1.5 MB。
8. **輸出**：`catalog.json`、`cache.json`、`status.json`、`README.md` 推到 **`binge-data` 分支**（每次強制推送、只留最新一版）；`me.json`、`roster.json` 有變才提交到 main。App 從 `raw.githubusercontent.com/PZWei0105/PZ-Games/binge-data/` 讀。

`status.json` 有這次執行的 `log`、`errors`、每台抓到多少——**維護時先看這個**。

### `catalog.json` 欄位（App 依賴這個格式）

```
{v:1, at, key, chs:[UC…], ch:[{n 名稱, a 頭像, k 類別, l 語言, vm 中位觀看, geo?, live?, kids?, official?, add?}],
 vids:[[id, 頻道序號, 標題, 片長, 時間, 觀看, 格式(c合輯|e單集|m劇場版|s短片|p預告|l直播|x片段), 旗標(1 AI|2 中文|4 有章節|8 即將直播|16 直播中), 作品序號(-1), 集數, 範圍起, 範圍迄]],
 shows:[{id:'p:'+清單 | 'g:'+頻道+':'+雜湊, n 名稱, c 頻道序號, k 類別, eps:[影片序號], t 更新時間, cv 封面影片, pl?}],
 chap:{影片:[[秒, 章節名]]}}
```

`me.json`：`{follow:{作品:{t,n}}, later:{影片:t}, blocks:{頻道:t}, hides:{作品:t}, prog:{影片:[位置,長度,t,裝置]}, adds:[{id,q,t,st}], seen, cursor}`

### App 這邊（localStorage 前綴 `binge.v1.`）

`set` 設定、`dev` 裝置代號、`seq` 事件序號、`out` 還沒被管線確認的事件、`base` 上一份 me.json、`hist`（影片：[最後看、看到第幾秒、片長、看完、累積毫秒、頻道、作品]）、`wt`（每天每類看了幾毫秒）、`showseen`（作品看到第幾集）、`days`（打開的天數＝第 N 話）、`visit`、`boot`。
長片（20 分鐘以上）的進度會送回管線，手機看到一半、電腦打開接著看。右上角燈號：綠＝都同步、黃＝等管線收件、紅＝送不出去。

## 播放

- YouTube 官方 IFrame 播放器（`youtube.com/embed`）：瀏覽器登入了 Premium 就沒有廣告；iPhone 的 Safari 擋第三方 cookie，可能還是有廣告——設定「點影片時：交給 YouTube App」。
- 外語片自動開中文字幕（`zh-Hant`）。
- 長片合輯：有章節就照章節跳「下一集」，沒有就照集數範圍平均估；時間軸上有刻度，看到哪一集會顯示「約第 N 集」。
- 跳過片頭（85／90／120 秒，設定）、速度 0.75～2 倍、睡前定時（15／30／45／60／90 分或「這支看完」：時間到音量慢慢轉小再停，記住看到哪）。
- 播完：同一部作品接下一集、不然照這一排接下一支；次回預告倒數 6 秒（連播可關）。
- 直式短劇：一個常駐的播放器＋上下兩張海報，滑動只動 transform，不會重建 iframe；「看完整版」會找同一部的長片合輯。
- **橫放全螢幕**（2026-11-19，痞子葳：「手機固定不會自動旋轉，但全螢幕時影片依然能橫放」）：手機上按全螢幕鍵不再交給 YouTube 自己的全螢幕（iPhone 那個會照直向鎖定，一直是直的），改用自己的 `Land`（`player.js`，在 `Swipe` 前面）：
  - iPhone：網頁不能轉螢幕、也不能整頁全螢幕（Safari 不支援 `screen.orientation.lock`、iPhone 只有影片元素能全螢幕），所以把 ``#thFrame`` 整個用 CSS 轉 90 度鋪滿（`--fx-*` 變數由 `Land.layout()` 算：影片保持 16:9、避開瀏海和底部橫條，右邊一定留 56 px 放按鈕，不蓋到 YouTube 播放器自己的字幕、設定鍵）。iframe 不搬家、只改 CSS，所以不會重新載入。
  - Android：`整個放映機 `#theater`` 真的全螢幕（藏掉瀏覽器和系統列），再 `screen.orientation.lock('landscape')`；系統不給轉，就一樣轉 90 度。電腦照舊。
  - 手機上 YouTube 播放器的全螢幕鍵藏起來（`fs: TOUCH ? 0 : 1`），免得按到那個又變直的。
  - 「轉手機自動橫放」（設定，預設開）：看 `deviceorientation` 算出手機哪邊朝上。從直的**很快**（1.5 秒內）轉成橫的、停 0.4 秒 → 自動進來；轉手機進來的，很快轉回直的、停 0.65 秒 → 退出；**按鍵進來的只用 ✕ 退出**（跟 YouTube App 鎖直向時一樣）。一直橫著（躺著側看）、慢慢躺下（轉超過 1.5 秒）都不會誤觸。橫著時翻到另一邊會跟著轉。
  - iPhone 要「動作與方向」權限：只能在點擊裡問，所以點影片、按全螢幕那一下順便問（同一次打開只問一次，答案記在 localStorage 的 `motion`；拒絕就不再自己問，到設定把開關關掉再打開會再問）。
  - 右邊的按鈕：✕ 退出、⟲ 反過來（轉 90 度時才有，方向記在設定 `landDir`）、片頭（跳過片頭出現時）、下一集（合輯有章節或集數範圍）或下一支。進來 3.5 秒後變淡，變淡時第一下只是叫醒（橫拿時拇指常常碰到邊邊）。全螢幕時的提示（toast）改寫在播放器裡、跟著轉。
  - 直式短劇本來就是直的，不受影響。

## 組建與測試

```bash
python3 _build/apps/binge/build.py               # 網頁版 → apps/binge/（不碰 data/）；畫面上新用到的顯示字會自動重做字型子集
python3 _build/apps/binge/build.py --icons       # 重畫圖示
python3 _build/apps/binge/tests/offline_test.py  # 管線離線測試（假 RSS、假清單、假轉發站）；--keep <資料夾> 留下假片庫
python3 _build/apps/binge/tests/shoot.py --data <資料夾> --out /tmp/bshots [--only phone,land,desk,fsx] [--sky night]   # fsx：橫放全螢幕檢查（12 項 PASS／FAIL）
```
`shoot.py`：手機直拿、橫拿、電腦三種截圖＋開場、扭蛋、作品頁、放映機（過場卡、次回預告、定時）、直式短劇、搜尋的流程；縮圖換成色塊、播放器換成假的。最後會列出**顯示字型缺的字**（畫面上用 Dela Gothic 卻沒在子集裡的字）和 console 錯誤。
沙盒連不到 YouTube／raw.githubusercontent.com：拿真資料用 `gh api "repos/PZWei0105/PZ-Games/contents/catalog.json?ref=binge-data" -H "Accept: application/vnd.github.raw"`；要用最新程式重算片庫，抓 `binge-data` 的 `cache.json` 跟 main 的 `roster.json`，直接呼叫 `pipeline.build_catalog(cache, roster['channels'], {})`。

沒有 Claude 版：artifact 不能嵌 YouTube 播放器、讀不到每 30 分鐘更新的資料（同《觀戰》）。

## 維護時注意

- **Dela Gothic One 是日文字型**，有些繁體字沒有（例如「內」「哪」「啟」「搞」）：顯示字型用到的文字要避開，`build.py` 會列出缺字，`shoot.py` 也會。換字比換字型好。
- 標題、作品名的整理規則改了，先跑 `offline_test.py`，再用真的 `cache.json` 重算片庫看一遍作品名（有沒有「限時免費」「第二集」這種名字跑出來）。
