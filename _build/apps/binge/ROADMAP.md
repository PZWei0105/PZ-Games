# 補番 BINGE — 待辦與已知問題

## 待辦
- 痞子葳接上 YouTube 金鑰（Actions 密碼 `YT_KEY`，跟《觀戰》共用一把）之後：確認台灣限定頻道（木棉花、Ani-One 中文）的播放清單、片長、直播狀態都有資料（看 `binge-data` 分支的 `status.json`：`key: true`）。
- 直播：目前片庫裡沒有直播中的馬拉松（直播分頁抓 4 台成功 2 台）；查 `status.json` 的 `errors`，必要時改用影片頁的 `isLiveNow` 補。
- 痞子葳實際在 iPhone／ROG Phone 上用過後：哪幾個頻道他常看、哪幾個從沒點，名單照這個調（`channels.json`）；AI 漫劇頻道品質落差大，看了覺得粗糙的就換掉。
- 木棉花精選的單集片長是 0：等影片頁慢慢補（每次 60 支）；補不齊再看要不要加大。

## 已知問題
- 橫放全螢幕只在電腦的瀏覽器（Chromium）測過：等痞子葳在 iPhone、ROG Phone 實際用過，確認轉 90 度後 YouTube 播放器的按鍵點得到、「動作與方向」權限多久問一次、Android 自動旋轉關著時會不會真的轉橫。
- iPhone 的 Safari／主畫面 App 擋 YouTube 的第三方 cookie：內嵌播放器可能有廣告。解法是設定「點影片時：交給 YouTube App」。
- 沒有金鑰時：台灣限定頻道只能靠說明欄裡的播放清單連結找作品，新上的作品會慢一點出現。
- 作品名靠標題猜：有些頻道標題完全不寫作品名（只寫劇情），這種影片會變成單支的合輯，不會合成一部作品。
- Dela Gothic One 是日文字型，少數繁體字沒有（內、哪、啟、搞⋯）：顯示字要避開，`build.py`、`shoot.py` 會列出缺字。

## 已完成
- 2026-11-19 1.2.0 橫放全螢幕：手機鎖直向也能橫著看（iPhone 轉 90 度鋪滿、Android 真的全螢幕再轉橫）；轉手機自動橫放（很快轉橫才算，躺著不誤觸；按鍵進來的只用 ✕ 退出）；右邊有退出、反過來、跳片頭、下一集／下一支；全螢幕時的提示寫在播放器裡。
- 2026-11-19 1.1.0 金鑰大更新：Muse、Ani-One 這類台灣限定頻道的播放清單內容改用 API 讀（美國的機器讀網頁常常讀不到，整季整套收得齊）；片庫每支檢查能不能嵌入（關掉嵌入／年齡限制／台灣看不到 → 卡片標「到 YouTube 看」、一點直接開 YouTube、自動下一支跳過）；名單外的「全天放送」（全網正在連播的動畫直播，四小時搜一次）、「全網熱補」（名單外一小時以上的長合輯，每天搜一次）。
- 2026-11-18 1.0.2：背景音樂完全不用白噪音（腳踏鈸拿掉、小鼓改成音高做的悶響、不進回音）。
- 2026-11-18 1.0.1：背景音樂拿掉黑膠底噪與爆擦聲（一直沙沙響像水聲，痞子葳嫌吵）。
- 2026-11-18 1.0.0 上線：放送、AI 動畫、番劇、片單；放映機（過場卡、跳過片頭、次回預告連播、睡前定時、合輯照章節跳集、長片進度同步）；直式短劇；扭蛋；補番數據；跟著時間變的天空與 OP；資料管線（RSS、yt-dlp 清單、影片頁、作品整理、繁體轉換、去重、每台預算、轉發站同步）。

- 金鑰接上後每週看 `status.json` 的 `units_day`（上限 4,000；《觀戰》另用最多 5,500）、`noembed`、`ext_live`、`ext_comp`。全天放送、全網熱補混進不像動畫的，調 `ANIME_RX`／`XBAD_RX`／`OK_CATS`。
