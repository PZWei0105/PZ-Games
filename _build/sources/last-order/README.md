# 最後一單 LAST ORDER — 原始碼（PZ 引擎版 2.0）

像素風殭屍求生動作（割草類）。五章劇情＋雙結局＋無盡模式「最後的碼頭」。
這是**第一款搬到《PZ 引擎》的舊遊戲**（2026-11-14）：玩法、關卡、劇情、數值、美術一個都沒改，換掉的是底下的「平台」——主迴圈、畫面放大與後製、震動與打擊感、聲音輸出、觸控搖桿、手把、存檔、設定頁、錯誤面板。

收藏庫裡的 `games/last-order/` 是打包後的版本，要改遊戲請改這裡。引擎本身在 `_build/engine/`（先看那裡的 `HANDBOOK.md`）。

## 組建

```bash
cd _build/engine
python3 tools/pzbuild.py ../sources/last-order          # 用 pz.json 指定的引擎版本（"1.0" ＝ releases/ 裡最新的 1.0.x）
python3 tools/pzbuild.py ../sources/last-order --dev    # 改引擎時：用 build/pz-engine.js（開發版）
```

產出：
- `dist/artifact/index.html`：Claude 版（單一檔案）。目前在 https://claude.ai/artifact/FKfdaq7SNNk1Gurv9Hdc11 。**發布之後要宣告能力 `{db: {}, user: {}}`**，雲端存檔才會動（之後用同一個頁面重新發布會沿用）。
- `dist/web/`：獨立網頁版（index.html＋manifest＋圖示）。整包複製到 `_build/raw/last-order/`，再照 `_build/README.md` 組收藏庫。

## 遷移做法（第一階段：換平台、不換畫法）

- 世界照舊用 Canvas2D 畫在 `VC.cv`（遊戲像素解析度，手機直拿約 206×446）。每格 `PZ.art.live('lo-world', VC.cv, { pixel: true })` 把它當貼圖，用最近鄰放大到全螢幕（像素清楚），再經過引擎的後製（泛光、衝擊波扭曲、色差、暗角、顆粒）。
- 引擎相機設成 `external`：位置跟遊戲自己的鏡頭（`G.cx/G.cy`），引擎只提供震動與後座力的位移（`PZ.cam.offsetX/Y`，在 `render()` 裡換算成遊戲像素加進去）。所以 `g.world()` 之後畫的東西（`drawOverlays`：槍口火光、爆炸、火焰的光暈）會疊在像素世界的同一個位置。
- 震動：原本的 `shake(v)` 改成引擎的 trauma 模型（平滑雜訊、會衰減），幅度換算成「遊戲像素」：`PZ.cam.maxX = 4.6 * VC.sc`，跟原本的幅度相同，但不再是每格亂跳。設定頁的「畫面震動」滑桿會作用。
- 打擊感（全部用引擎的 `PZ.fx`）：受傷（紅色暗角＋色差＋被撞一下＋手機震動）、爆炸與 Boss 震地（衝擊波扭曲＋閃光＋重震動＋手把震動）、霰彈槍與鋁棒的後座力、爆擊色差、升級閃光、Boss 登場暗紅暗角、擊倒 Boss 白閃＋大衝擊波（慢動作沿用遊戲自己的 `G.slow`，不要再疊 `PZ.slowmo`）。
  - 自動連射的手槍、步槍**不加**後座力：一秒好幾發，畫面會一直抖。
- 邏輯維持固定步長 `step: 1/60`，跟原本的手感一模一樣。
- 設定頁的「傷害數字」「閃光」會作用在遊戲自己畫的數字和閃電上；劇情文字速度接引擎的 `textSpeed`。

第二階段（之後）：把人物、殭屍、粒子改成引擎的圖集＋批次繪製，就能用引擎的光照、更多粒子、更大的同屏數量。做之前先在這裡記下計畫。

## 輸入

- 觸控：畫面任一處按住拖曳＝浮動搖桿（`PZ.input.stick`，樣子沿用原本的圓圈＋橘色把手，class `lo-stick`）；右下翻滾、汽油彈、換槍是原本的 DOM 按鈕。
- 鍵盤：WASD／方向鍵移動（引擎的 `PZ.input.move`）；空白鍵翻滾、F／E 汽油彈、Q 或 1–3 換槍、Esc／P 暫停——在 `App.onKey`（`11_app.js`）。
- 手把：左類比移動、A 翻滾（劇情：下一句）、X／RB／RT 汽油彈、Y／LB 換槍、START 暫停、B 返回／繼續、BACK 跳過劇情。
- 選單用手把／鍵盤：`PadNav`（`13_engine.js`）把最上層看得到的畫面登記成引擎的介面層，方向鍵移動焦點、A／Enter 按、B／Esc 返回。
  - **畫面出現後要等一下才接手**（升級卡 0.6 秒、其他 0.35 秒），狂按翻滾時跳出升級卡才不會被誤選。
  - 劇情只有在「選擇」時才接手（不然空白鍵會同時「下一句」又按到「跳過」）。
  - 暫停選單的 Esc 由遊戲自己處理，`PadNav.back` 不要再接 `UI.resume`（會變成「繼續→又暫停」）。

## 存檔

- `PZ.save.open('last-order', …)`：本機自動存＋備份（主存檔壞掉會讀備份）、設定頁可以複製／貼上存檔碼（Claude 版與網頁版互通）。
- **舊版存檔自動搬家**：第一次打開引擎版時，如果還沒有新存檔，會把舊的 `lastorder.v1` 整份搬過來（進度、成就、統計都在）。舊版的「音效：關」會變成這款的音量 0（`{ local: true }`，不會帶到別款遊戲）。
- **雲端（只有 Claude 版）**：引擎自動把存檔另外寫到 `db` 的 `data/users/<自己>/save`。開機時引擎的載入畫面先等雲端回話（最多 5 秒）再顯示標題。
- 任何從外面讀進來的存檔（存檔碼、雲端）都經過 `Save.fix()` 補齊欄位，`PZ.on('saveload')` 會刷新標題畫面。
