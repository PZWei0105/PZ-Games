# 留一口 LEAVE ONE — 企劃

## 一句話

冰河期末，你是部落的獵人。你打不贏猛獁象，所以要讓整座山替你動手。

## 支柱

1. **借力使力**：真正殺死猛獁的是火、風、冰和牠自己的恐懼；矛只是開頭。
2. **看得懂的因果**：火往哪燒看風（左上角＋飄雪），猛獁照本能動（頭上的字），落點與打到的部位出手前就畫出來。輸了要知道為什麼。
3. **沒有標準解**：最安全的打法（火趕上冰）收穫最少；收穫最多的打法（扎矛放血、用火擋衝鋒）最危險。風每回合變。
4. **火光下會動的岩畫**：整個遊戲畫在洞壁上，火真的會照亮岩面；結束時，這一場留在牆上，旁邊噴上你的手印。

## 這一版（30 秒玩具）的範圍

一個獵人、一頭猛獁、草原、冰湖、風；矛 3 支、火把 2 支。
目的：驗證「丟第一矛、點第一把火」就想再來一場。不好玩就整個打掉，不靠美術遮醜。

## 之後（如果玩具成立）

- 一個季節做到成品質感當標準，再擴充獸種（野牛群、劍齒虎、狼）、工具（多一種招式，不是加數值）、世代。
- 「留一口」：獵光了，下個冬天山就是空的；結局從你的獵法長出來。
- 2～3 人連線合獵（規則與畫面已經分開，留了路）。
