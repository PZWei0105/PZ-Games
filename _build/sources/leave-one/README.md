# 留一口 LEAVE ONE — 原始碼

冰河末的回合制狩獵（試作：第一場狩獵）。一個獵人、一頭猛獁、草原、冰湖、風。畫面是「火光下會動的岩畫」：
整個世界畫在洞壁上，WebGL 依火光替凹凸的岩面打光，顏料層（2D canvas）每格重畫、再貼到岩面上。
純 JavaScript，沒有框架、沒有外部函式庫；字型是 Noto Serif TC 的子集，組建時內嵌。
收藏庫裡的 `games/leave-one/` 是打包後的單檔版本，要改遊戲請改這裡。企劃在 `DESIGN.md`。

## 組建

```bash
python3 build.py        # dist/artifact/index.html（Claude 版）與 dist/web/（獨立網頁版：index.html＋manifest＋圖示）
python3 tests/icon.py   # 用遊戲畫面重做 App 圖示（assets/icon-*.png），之後再 build 一次
```

把 `dist/web/*` 複製到 `_build/raw/leave-one/`，再照 `_build/README.md` 的流程組收藏庫。
Claude 版：用 artifact 工具發布 `dist/artifact/index.html`。存檔只用 localStorage（前綴 `leaveone.v1.`：看過的提示、狩獵場數、最好的一次收穫）。

## 結構（`src/` 依檔名順序串成一支 script）

| 檔案 | 內容 |
|---|---|
| `00_head.html` | HTML 骨架、全部 CSS（石板＋赭紅）、HUD、標題、結局、選單、怎麼玩、直拿提示 |
| `01_util.js` | 數學、亂數（mulberry32）、雜湊與一維雜訊、`store`、顏料色 `PIG` |
| `02_world.js` | 規則（不碰畫面）：地形、草的燃料段、冰的厚度段、風（每回合變、預告下一回）、擲物物理與預測、命中部位、火的蔓延、冰的承重、猛獁本能狀態機、流血、收穫 |
| `03_paint.js` | 顏料層：地面、岩塊、湖與冰、草、火焰、矛與火把、獵人（黎凡特岩畫式人形）、猛獁（肖維式奔跑殘影、要害的心） |
| `04_gl.js` | WebGL：一次產生整面洞壁（岩色＋高度）、每格合成（法線打光、顏料顆粒、色調、暗角）、加亮的發光點 |
| `05_fx.js` | 粒子：餘燼、煙、雪（看風向）、塵、血滴與地上的血跡、冰屑、水花、蒸氣、結局的手印噴點 |
| `06_decor.js` | 洞壁上前人留下的褪色舊畫（手印、馬、野牛、鹿、點列、記號），烤進岩面 |
| `07_audio.js` | WebAudio 即時合成：心跳鼓（獸越躁越急）、低鳴、風、火、洞穴回音、矛、象吼、腳步、冰的「咻」聲與碎裂、水花、骨笛 |
| `08_ui.js` | 工具鈕、風向板、提示佇列、猛獁狀態標籤、瞄準落點標籤、傷害字、結局卡 |
| `09_main.js` | 鏡頭（自動取景＋捏合縮放）、拉放瞄準、回合流程、事件→聲光、燈光與發光、畫面合成、主迴圈（卡頓自動降解析度）、`window.__lo` 測試掛鉤 |

## 規則重點（要改平衡先看）

- 回合：玩家出手（或「等一回」）→ 東西飛完 → 世界跑 `TURN_TIME`（2.4 秒）→ 換風 → 下一回。玩家回合時世界是靜止的（只有火光、雪、呼吸在動）。
- 火：每 16 單位一段草。順風每秒 70＋50×風力，逆風幾乎不動，無風兩邊慢慢燒；燒完變灰，不會再燒。
- 猛獁（`MAM`）：怕火（`fear` 250 內逃、`panic` 175 內才肯衝上冰）；被矛扎到就發狂衝向獵人（先刨地 `windup`），火在前面就停下來、轉身逃；只有發狂衝鋒會爬上石坡，逃命時跑到坡底或湖邊會被逼住。
- 矛：部位傷害 `DMG`；矛留在身上，跑得越快血流越快（要害算兩支）。
- 冰：薄冰撐不住猛獁（走 0.55／小跑 0.65／狂奔 0.75 對上冰厚），一踩上去開始碎、約 0.4 秒後裂開。火把落在冰上 −0.3。
- 收穫 `harvest()`：沉進冰湖只剩一點肉；被火燒過肉焦皮壞；三支矛以上皮會破。

## 測試（需要 Playwright＋/usr/bin/google-chrome）

```bash
node tests/sim.js 60              # 規則：六種打法各打 60 場，看結果分布與收穫
python3 tests/run.py shots land   # 標題、開場、瞄準、飛行、衝鋒、火牆截圖到 /tmp/lo（land／desk／phone）
python3 tests/run.py flow ice     # 自動玩一整場：順風火攻趕上冰
python3 tests/run.py flow bleed   # 自動玩一整場：扎矛放血＋火牆
python3 tests/run.py perf         # 每格 JS 時間
```
