# 《長明》第一章素材清單

> 規格看 `ART_BIBLE.md`，做法看 `BLUEPRINT.md`。
> 開工後，筆電 Code 把這份清單轉成製作清單 `art/production.json`（每項一筆：id、類型、規格、狀態、分數、母圖位置、輸出檔），之後以它為準，這份文件不用再改。
> 優先順序：**P0 魏子葳樣板 → P1 角色 → P2 敵人與頭目 → P3 場景 → P4 介面、圖示、特效、主視覺**。
