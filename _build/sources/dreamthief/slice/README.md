# 竊夢者・試玩關（橫版重做）

照《無盡輪迴：鬼域摸金》的核心重做的一小關，先給 PZ 試玩；通過了才換掉收藏裡的舊版。

一局：千禧大樓（1F 大廳 → 7F 辦公室 → 13F 診所 → 天台）的剖面，一層一層往上搜。

- 夢魘從發紅的裂縫一波一波湧出，清完一波有 10 秒喘息。
- 門擋得住夢魘、子彈打得穿門縫；站在門邊會自己修。上鎖的門要夢幣或鑰匙。
- 放大鏡一圈一圈搜（綠＜藍＜紫＜金＜紅），越稀有越久；大多當場用掉（夢幣、鐘擺零件、醒神糖、靈光），只有記憶進背包（10 格，滿了自動換掉最便宜的）。
- 靈光三選一：夢具（自動施放，最多三件）或強化。
- 清醒度（時間、開房、開鎖、清波都會漲）滿 100 → 心魔「值班台」出現在天台、封住鐘。
- 天台敲鐘、待在天台撐 30 秒撤離；夢中人自己走到天台，從鐘撤離才帶得走他們的記憶。湊齊 6 個鐘擺零件可以緊急醒來。

## 組建與測試

```
python3 build.py                 # → dist/index.html（共用 ../src 的樣式、聲音、角色手繪、老韓的資料）
python3 tests/run.py shots       # 直式截圖 → /tmp/sv/shots
python3 tests/run.py bot 4 150   # 自動試玩（4 倍速、最多 150 秒）
python3 tests/run.py land        # 橫式、桌機截圖
python3 tests/run.py perf        # 每格繪圖時間
```

程式：`src/20_data.js` 關卡與數值、`21_world.js` 規則、`22_render.js` 畫面、`23_ui.js` 介面、`24_main.js` 操作與主迴圈；`src/00_head.html` 是追加樣式和介面骨架（`<!--BODY-->` 前是 CSS）。
