# PZ App 引擎（PZ App Kit）

痞子葳專屬 App 的共用引擎＋設計理念手冊（2026-11-21 起）。遊戲用的是另一套《PZ 引擎》（`_build/engine/`）。

**一句話**：把冷眼和解包最好的做法（門鎖、資料自己校正、新版本真的送到手機、聲音、動態、不互相打架的本機儲存）做成一套，之後的新 App 直接拿來用；再加上護欄——App 改壞了，網站會自動換回上一個好的版本。

## 它保證什麼
- **已經上線的 App 不會因為引擎改版而變樣**：每個 App 用的是引擎某一版的完整複本（`releases/`，發出去就永遠不改）。
- **改壞了回得去**：推上去之後 GitHub Actions 用真的瀏覽器照你的用法打開一遍（手機直拿、橫拿、電腦、每一套換裝、沒開過的裝置要停在鎖），沒過就自動把網站換回上一個好的版本，資料照樣最新；任何時候也能一鍵換回第 n 個好的版本。
- **好的做法傳下去**：`HANDBOOK.md` 第 2 節是從冷眼和解包整理出來的 16 條設計理念，每個新 App 交件時都要逐條對照。

## 它不做什麼
- **冷眼永遠獨立**：冷眼不用這套引擎、不搬、不改；冷眼有自己的門鎖和護欄。
- **解包最後才搬**：等一個新 App 用引擎實際上線、跑過兩週沒出事、你也同意，才把解包一塊一塊搬上來，而且畫面要和搬之前一模一樣。
- 門鎖是**門鎖，不是加密**：擋的是別人拿到你的手機或電腦隨手打開；你的私人資料本來就只在你的手機，沒有上傳。

## 給 Claude
- 說明書：`HANDBOOK.md`（先看第 0 節鐵律、第 2 節設計理念、第 11 節交件檢查清單）。
- 組建：`python3 tools/build_appkit.py`（開發版）、`--release`（正式版）；全套檢查：`python3 tools/test_appkit.py --guard`。
- 護欄：`python3 _build/appkit/py/guard.py check|run|rollback|status <app>`（在 repo 根目錄）。
- 版本紀錄：`CHANGELOG.md`。
